HOW TO USE
- Put the "newvision" kit and `newvision-tutorial-builder.md` in your repo.
- Open Claude Code in the repo root.
- Run these prompt files ONE AT A TIME, in order (01 -> 27).
- Each writes one JSON file to wwwroot/tutorials/<slug>.json and self-verifies.
- Do NOT run several at once — one topic per run keeps quality high.

RULES BAKED INTO EVERY PROMPT
- No company/client name anywhere (vendor-neutral; only the Microsoft/Azure
  technologies the topic is actually about are named).
- All 21 canonical sections, >=15 quiz, >=15 exam, >=15 flashcards, >=15
  interview Q&A, full glossary + tooltips, Step-5 self-audit.
- prev/next are set so the 27 form one ordered learning path.
